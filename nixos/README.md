# NixOS

Flake-based NixOS configuration for the Framework 13 Pro, with Home Manager as a NixOS module.

## Apply

```sh
sudo nixos-rebuild switch --flake ~/Development/dotfiles/nixos#framework
```

## Update packages

```sh
nix flake update --flake ~/Development/dotfiles/nixos   # bumps flake.lock
sudo nixos-rebuild switch --flake ~/Development/dotfiles/nixos#framework
```

Commit `flake.lock` afterwards; it records the exact versions the system was built from.

## Layout

| File | Purpose |
| --- | --- |
| `flake.nix` | Inputs (nixpkgs, home-manager, zen-browser) and the `framework` system |
| `configuration.nix` | System settings |
| `hardware-configuration.nix` | Generated by `nixos-generate-config`; don't edit by hand |
| `home.nix` | Home Manager entry point for `austin` |
| `vscode.nix`, `agents.nix` | Home Manager modules imported by `home.nix` |

New files must be `git add`ed before rebuilding: flakes only see files git tracks.

## One-time setup outside Nix

- YubiKey for sudo: `pamu2fcfg -N > ~/.config/Yubico/u2f_keys` (key needs its FIDO2 PIN)
- Fingerprint: `fprintd-enroll`
